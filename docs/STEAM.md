# Игра с друзьями через Steam

## Как это работает
- Игра использует **Steamworks** (библиотека Steamworks.NET): лобби, приглашения друзей и P2P-соединение
  через релеи Valve. Порты открывать не нужно, IP-адрес не раскрывается.
- Пока у игры нет своего App ID, используется тестовый **480 (Spacewar)** из файла `steam_appid.txt`.
  Поэтому в профиле Steam друзья будут видеть «Играет в Spacewar». Это нормально.

## Подготовка (у каждого игрока)
1. Соберите игру: в Unity **File → Build Profiles → Windows → Build** и выберите папку, например `Build/`.
   Файл `steam_appid.txt` скопируется в папку сборки автоматически.
2. Отправьте папку сборки друзьям (например, в zip-архиве). **Версии у всех должны совпадать.**
3. Каждый добавляет игру в Steam: **Игры → Добавить стороннюю игру в мою библиотеку… → Обзор…** →
   выбрать `Your Last Order.exe`.
4. Запускайте игру **из библиотеки Steam**. Тогда работает оверлей Steam (Shift+Tab), а через него — приглашения.

## Создать игру и позвать друзей
1. Хост: **Играть с друзьями → Создать лобби**.
2. Позвать друзей можно двумя способами:
   - **«Пригласить друзей»**: откроется оверлей Steam со списком друзей;
   - **«Копировать»** рядом с кодом лобби: отправьте код другу в чат.
3. Друг:
   - **по приглашению**: игра у него должна быть **уже запущена**. Друг нажимает «Принять» в чате
     или оверлее Steam, и игра подключится сама;
   - **по коду**: **Играть с друзьями → вставить код → Войти по коду**.
4. Когда все в лобби, хост нажимает **«Начать смену»**.

> ⚠️ **Ограничение тестового App ID 480.** Если игра у друга не запущена, при принятии приглашения
> Steam попробует запустить Spacewar, а не нашу игру. Поэтому пусть друг сначала запустит игру,
> а потом принимает приглашение (или входит по коду). С собственным App ID (Steam Direct, $100)
> приглашение будет само запускать игру, а у друзей будет отображаться её настоящее название.

## Игра по IP (без Steam)
**Играть с друзьями → По IP**: хост нажимает «Создать», друзья вводят его IP и порт `7777`
и нажимают «Подключиться». Для игры через интернет нужен проброс UDP-порта 7777 у хоста
или общая виртуальная сеть (Radmin VPN, ZeroTier, Tailscale).

## Если что-то не работает
| Симптом | Решение |
|---|---|
| Внизу меню «Steam недоступен» | Запустите Steam до игры. Проверьте, что рядом с .exe лежит `steam_appid.txt` с числом 480. |
| Кнопка «Пригласить друзей» неактивна | Оверлей Steam выключен или игра запущена не из Steam. Используйте код лобби. |
| «Это лобби другой игры» | Код от лобби другой игры на App ID 480. Проверьте код. |
| Долгое «Подключение…» | У хоста и друга должны совпадать версии сборки. Попробуйте ещё раз: первое P2P-соединение через релей может занять до 10–15 с. |
