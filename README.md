# Your Last Order — Твой Последний Заказ

Кооперативный хоррор на Unity 6 (1–4 игрока): роботы-курьеры компании «You Can Buy Everything»
развозят посылки по уровням в стиле Backrooms. Полный дизайн — в [docs/GDD.md](docs/GDD.md).

## Состояние
Веха **M0 (прототип) в работе**. Уже написаны скрипты сети, игрока, фонарика, монстра и раунда
(`Assets/_Project/Scripts`). Сцены пока нет: HUD и редактор-скрипт сборки уровня ещё не написаны.

## Требования
- Unity **6000.0 LTS** (Unity 6)
- Пакеты подтягиваются из `Packages/manifest.json` (Netcode for GameObjects, AI Navigation)

## Структура
```
Assets/_Project/Scripts/
  Networking/   подключение, одобрение игроков, спавн
  Player/       управление, фонарик, взаимодействие, звуки шагов, эффекты страха
  AI/           монстр (зрение, слух, погоня)
  Game/         логика раунда, предметы, выход
  Environment/  окружение (мерцающие лампы)
  Audio/        процедурные звуки-заглушки
docs/GDD.md     дизайн-документ и план разработки
```
